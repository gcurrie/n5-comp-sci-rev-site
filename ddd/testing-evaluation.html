Testing SQL Queries

To test an SQL statement, run the query and compare the actual output on screen with the expected output — the results the query should produce. If they don't match, there is an error to correct.

Example — a query that fails its test

A query is supposed to find all the red cars, but it was written as:

SELECT Registration, Make, Model
FROM Car
WHERE Colour = "Green";

The actual output (green cars) doesn't match the expected output (red cars) — the condition needs corrected to Colour = "Red".

ℹ️
Unlike software development, you do not need to talk about normal, extreme or exceptional testing for databases — testing means checking that SQL operations work correctly.

Fitness for Purpose

A database (or query) is fit for purpose when it satisfies the functional requirements from the analysis stage — every required table exists and every required query works, verified through testing.

💡
Answer format (usually 2 marks): "The database is fit for purpose because…" or "The database is not fit for purpose because…" — one mark for the judgement, one for the justification tied to the requirements.

Accuracy of Output

Accuracy of output is closely related to testing — it asks whether the queries produce the expected results. Your testing evidence (expected vs actual output comparisons) is exactly what supports a claim that the output is accurate.

Test Yourself

Q1 — Evaluate the database (2 marks)

A café's functional requirements said the database needed a query showing all gluten-free items sorted by price. The finished query shows gluten-free items but unsorted. Evaluate the database's fitness for purpose.

Marking Instructions

The database is not fully fit for purpose (1 mark) because the query does not meet the functional requirement to sort the results by price — the ORDER BY is missing (1 mark).

Q2 — Testing (2 marks)

Describe how you would test that a SELECT query works correctly.

Marking Instructions

Run the query on the database (1 mark) and compare the actual output with the expected output worked out beforehand — if they match, the query works correctly (1 mark).
