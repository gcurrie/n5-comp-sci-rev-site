The SELECT Query

At National 5 you must be able to read, understand, explain and write SQL SELECT queries. A SELECT query searches or sorts a database, and follows this structure:

SQL — the full structure
SELECT Registration, Make, Model
FROM Car
WHERE Colour = "Blue"
ORDER BY Mileage DESC;
  • SELECT — the field(s) to display
  • FROM — the table the data comes from
  • WHERE — the search condition (optional)
  • ORDER BY — the sort order (optional)

Without the optional clauses, the query displays every record. To show all fields, use the asterisk wildcard:

SQL — all fields, all records
SELECT *
FROM Car;

Sorting with ORDER BY

Use ASC to sort A→Z / smallest→largest, or DESC for the reverse. At N5, you can sort on a maximum of two fields:

SQL — sorting
SELECT Registration, Make, Model
FROM Car
WHERE Colour = "Blue"
ORDER BY Registration ASC;

-- Two-field sort: by make A-Z, then newest first within each make
SELECT *
FROM Car
ORDER BY Make ASC, Year DESC;

Complex Conditions — AND & OR

The WHERE clause can combine conditions with AND and OR, and use the <, > and = operators:

SQL — multiple conditions
-- Both conditions must be true
SELECT Registration, Make, Model
FROM Car
WHERE Colour = "Red" AND Year = 2009;

-- Either condition can be true
SELECT Registration, Make, Model
FROM Car
WHERE Colour = "Red" OR Colour = "Blue";

-- A range
SELECT Registration, Make, Model
FROM Car
WHERE Year >= 2009 AND Year <= 2018;

Reading a Query's Output

The other common exam question gives you a query and asks you to state or describe its output. Use a three-step method:

Worked Example — what does this query display?
SELECT Make, Model, Registration
FROM Car
WHERE Colour = "Black";
RegistrationMakeModelColourYear
SK19 TREFordFiestaRed2019
ST99 FDTVolkswagenGolfBlack2017
SG02 PLMVauxhallCorsaBlue2015
SH88 NNGNissanQashqaiBlack2018
  1. Identify the fields to display — the SELECT clause gives the column headings: Make, Model, Registration.
  2. Check the WHERE condition — Colour = "Black". Two cars match: the Volkswagen and the Nissan.
  3. Extract the information for the matching records only.

Output:

MakeModelRegistration
VolkswagenGolfST99 FDT
NissanQashqaiSH88 NNG

Test Yourself

Q1 — Write a query (3 marks)

Using the Car table above, write a query to display the registration and year of all cars newer than 2016, with the newest first.

Marking Instructions
Suggested answer
SELECT Registration, Year
FROM Car
WHERE Year > 2016
ORDER BY Year DESC;

1 mark: SELECT/FROM with correct fields and table. 1 mark: correct WHERE. 1 mark: correct ORDER BY … DESC.

Q2 — State the output (2 marks)

Using the Car table above, state the output of:

SELECT Registration
FROM Car
WHERE Colour = "Red" OR Colour = "Blue";
Marking Instructions

A single Registration column containing SK19 TRE (red Fiesta) and SG02 PLM (blue Corsa). (1 mark for correct records, 1 mark for showing only the Registration field)
