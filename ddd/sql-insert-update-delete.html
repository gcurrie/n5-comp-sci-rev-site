INSERT INTO … VALUES …

As well as searching and sorting, you may have to add, change or delete data. INSERT INTO adds a completely new record. Write the table name, then list each value in the order the fields come in the table:

SQL — INSERT INTO
INSERT INTO Car
VALUES ("Ford", "Focus", "Blue", 2020);

INSERT INTO Pupil
VALUES ("Jasmine", "Smith", "S4", "123 Hamilton Street");
⚠️
The values must match the field order. If the Pupil table's fields are forename, surname, yearGroup, address, then VALUES ("Jasmine", "Smith", "123 Hamilton Street", "S4") puts the address in the year group field!

UPDATE … SET … WHERE …

UPDATE changes existing records. It always goes in this order: UPDATE the table, SET the new value, WHERE to choose which records change:

SQL — UPDATE
UPDATE Car
SET Year = 2019
WHERE Colour = "Red";

-- Move every S4 pupil up a year group
UPDATE Pupil
SET YearGroup = "S5"
WHERE YearGroup = "S4";

DELETE FROM … WHERE …

DELETE FROM removes whole records — you cannot delete just one field from a record:

SQL — DELETE FROM
DELETE FROM Car
WHERE Colour = "Red";

-- Compound condition
DELETE FROM Car
WHERE Year >= 2009 AND Year <= 2018;
⚠️
Always use a WHERE clause with UPDATE and DELETE — without one, the command changes or removes every record in the table.

Test Yourself

Q1 — Write the queries (3 marks)

A Member table has the fields: memberID, forename, surname, town. Write SQL to:

  1. Add member 205, "Eilidh", "Ross", from "Troon".
  2. Change every member from "Prestwick" to "Ayr".
  3. Remove member 118.
Marking Instructions
Suggested answers
INSERT INTO Member
VALUES (205, "Eilidh", "Ross", "Troon");

UPDATE Member
SET Town = "Ayr"
WHERE Town = "Prestwick";

DELETE FROM Member
WHERE MemberID = 118;

1 mark each for a correct INSERT (values in field order), UPDATE (SET before WHERE) and DELETE (with WHERE).

Q2 — Explain the error (2 marks)

A pupil runs DELETE FROM Member; intending to remove one member. Describe what actually happens, and how the query should have been written.

Marking Instructions

Every record in the Member table is deleted, because there is no WHERE clause (1 mark). It should include a condition identifying the member, e.g. DELETE FROM Member WHERE MemberID = …; (1 mark).
