Databases — Key Terminology

A database is a collection of information on a particular topic that is structured in some way — a database of football teams, a CD collection, or the books in a library. Databases are organised into fields, records and tables:

Field
A single piece of information about a person or thing — e.g. a pupil's name, date of birth or address. A field is also known as an attribute.
Record
A collection of fields about one particular person or thing — e.g. one record for each pupil in a school.
Table
A collection of records on a particular topic — e.g. a table containing a record for every pupil in the school.
Example — a school pupil table
ForenameSurnameDateOfBirthYearGroup
AishaKhan04/02/2010S4
CallumReid19/09/2009S5
IonaMurray30/06/2010S4

Each column is a field (attribute); each row is a record; the whole thing is a table.

Field / Attribute Types

Each attribute in a database must be assigned a type, which specifies what sort of data the field will hold. The National 5 attribute types are:

TypeStoresExample
TextLetters, numbers and symbols"Aisha", "KA7 2RG"
NumberNumeric values15, 2.49
DateA calendar date04/02/2010
TimeA time of day09:15
BooleanOnly TRUE or FALSEhasPaid = TRUE
⚠️
In MS Access, Date and Time fields are called Date/Time and Boolean fields are called Yes/No. You must not use the MS Access names when designing your database or answering exam questions — use the SQA types above.

Test Yourself

Q1 — Terminology (3 marks)

A vet's database stores information about pets. Match the terms field, record and table to: a) all the information about one pet; b) all of the pets; c) a pet's name.

Marking Instructions

a) Record. b) Table. c) Field (attribute). (1 mark each)

Q2 — Attribute types (3 marks)

State the most suitable attribute type for: a) a pet's appointment time; b) whether its vaccinations are up to date; c) the owner's phone number "07700 900123".

Marking Instructions

a) Time. b) Boolean. c) Text — the leading 0 and space would be lost if stored as a number! (1 mark each)
