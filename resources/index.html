✅Revision Checklists

💻 Software Design & Development
  • ☐ Iterative development process (the six phases)
  • ☐ Analysis (purpose, inputs, processes, outputs)
  • ☐ Design notations (structure diagrams, flowcharts, pseudocode)
  • ☐ Wireframes (user-interface design)
  • ☐ Data types (character, string, integer, real, Boolean)
  • ☐ Variables and 1-D arrays
  • ☐ Selection (if/elif/else, AND, OR, NOT)
  • ☐ Loops (fixed and conditional)
  • ☐ Pre-defined functions (random, round, length)
  • ☐ Standard algorithms (input validation, running total, traversal)
  • ☐ Testing (normal/extreme/exceptional data; syntax/logic/execution errors)
  • ☐ Evaluation (fitness for purpose, efficiency, robustness, readability)
🗄️ Database Design & Development
  • ☐ Fields, records, tables and attribute types
  • ☐ End-user and functional requirements
  • ☐ UK GDPR implications
  • ☐ Entities, attributes and one-to-many relationships
  • ☐ Primary keys, foreign keys and referential integrity
  • ☐ Data dictionaries (types, sizes, four validation types)
  • ☐ ER diagrams
  • ☐ SQL SELECT with WHERE and ORDER BY (two fields max)
  • ☐ Equi-joins between two tables
  • ☐ SQL INSERT, UPDATE, DELETE
  • ☐ Testing queries; fitness for purpose; accuracy of output
🖥️ Computer Systems
  • ☐ Binary ↔ denary conversion (positive integers)
  • ☐ Floating-point (mantissa and exponent)
  • ☐ Extended ASCII (8-bit)
  • ☐ Bit-mapped graphics (grid of pixels)
  • ☐ Vector graphics (objects and attributes)
  • ☐ Processor (registers, ALU, control unit), memory, buses
  • ☐ Interpreters and compilers
  • ☐ Environmental impact (energy-saving settings)
  • ☐ Firewalls and encryption

🎯General Exam Tips

📖
Read the question carefully. Note exactly how many marks are available — each mark typically requires a distinct point.
💬
Use technical language. Use correct computing terminology — "interpreter", "iteration", "primary key" — rather than vague descriptions.
🧮
Show your working. For binary conversion questions, always show each step — you can gain marks for method even if the final answer is wrong.
⏱️
Time management. The paper is 1 hour 30 minutes for 80 marks — just over a minute per mark. Don't spend too long on any single question.
🔄
Apply to context. When evaluating, always refer back to the specific scenario in the question rather than giving generic answers.
✅
Check SQL syntax. In SQL questions, check the clause order, quotes around text values, and the WHERE conditions — and never forget the equi-join in two-table queries.
