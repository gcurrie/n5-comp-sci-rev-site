Data Dictionary Filler

Read what the customer needs, then fill in the missing cells — exactly the task the exam sets. Start with the school database you already know, then try three you have not seen.

Three marks people throw away: Size is filled in for Text and nothing else · the primary key is always Required = Yes · a borrowed key is FK, not PK. And this is a database, so it is Text and Number — never "string", "integer" or "real".
