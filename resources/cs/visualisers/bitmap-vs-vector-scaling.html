Bitmap vs Vector — Scaling Up

The same shape, enlarged by the same amount, stored two different ways. The bitmap can only make its stored pixels bigger, so it goes blocky. The vector recalculates the objects at the new size, so the edges stay sharp however far you push it.

Notice that neither file changed size as you zoomed. The bitmap still stores the same number of pixels and the vector still stores the same objects — what changed is only how they are displayed. That is the whole point: a bitmap has a fixed amount of detail baked in when it is saved, while a vector works out the detail fresh every time it is drawn.
