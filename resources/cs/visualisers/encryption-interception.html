Encryption & Interception

Send a message across a network that somebody is listening to. The point to watch: encryption does not stop the message being intercepted — it stops the interception being any use.

Real encryption uses far more complicated maths — but at National 5 you are never asked how data is scrambled, only that it is scrambled, so that anyone intercepting it cannot read it without the key.
