Introduction

All of the programs you have written until now were very static — they did the same thing every time. That isn't how real software works. Applications like Netflix and games respond to user input, making software dynamic and interactive.

The Input Statement

When you want the user to enter data, use an input statement. The message inside the brackets is the prompt that the user sees:

Python — inputting strings
# Enter some data from the keyboard
name = input("Please enter your name")
title = input("Enter book title")
author = input("Enter book author")
genre = input("Enter book genre")

The input statement will be used in almost all of your programs.

Input with Numbers — Casting

When you input numbers there is an extra step. Any data that you input is automatically assumed to be a string — so before you can do calculations with it, you must convert (cast) it to the right type:

Python — casting input
# When you input a string...
name = input("Please enter your name")

# When you input an integer number, use int( )
age = int(input("Enter age"))

# When you input a real number, use float( )
price = float(input("Enter price"))
⚠️
Forgetting int() or float() is one of the most common National 5 mistakes — the program will crash (or behave strangely) the moment you try a calculation on a string. Note: casting doesn't work for Booleans (True/False).
Full example — inputs then outputs
Python
# User inputs
name = input("Please enter your name: ")
age = int(input("Please enter your age: "))

# A different layout for user inputs
print("Please enter your height")
height = float(input())

# Printing user input
print("My name is " + name + " and I'm " + str(age))
print("I'm " + str(height) + " metres tall")

Input in SQA Reference Language

In exam papers, input is written with RECEIVE … FROM KEYBOARD, with the data type shown in brackets:

SQA Reference Language
RECEIVE name FROM (STRING) KEYBOARD
RECEIVE age FROM (INTEGER) KEYBOARD
RECEIVE height FROM (REAL) KEYBOARD
RECEIVE initial FROM (CHARACTER) KEYBOARD
RECEIVE hasPaid FROM (BOOLEAN) KEYBOARD

Test Yourself

Q1 — Spot the problem (2 marks)

This program crashes when it runs. Identify the error and rewrite the faulty line.

age = input("Enter your age")
nextYear = age + 1
print(nextYear)
Marking Instructions

input() returns a string, so age + 1 tries to add a number to text (1 mark). Fix: age = int(input("Enter your age")) (1 mark).

Q2 — Choosing the cast (2 marks)

State the casting function needed to input: a) the price of an item in pounds and pence; b) the number of tickets to buy.

Marking Instructions

a) float() — price is a real number (1 mark). b) int() — number of tickets is a whole number (1 mark).
