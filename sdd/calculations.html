Introduction

You can now get data into a program and results out — this page fills in the middle: the processes. At National 5, that mostly means calculations built from five arithmetic operators, with the results stored in variables. And because not everything we join together is a number, we'll also cover concatenation — sticking strings together.

Key Terms

Operator
A symbol that performs an operation on values — like + for addition or * for multiplication.
Expression
A calculation that produces a value, e.g. num1 + num2. Expressions are used to assign values to variables.
Exponentiation
Raising a number to a power — 5 ** 2 is 5², which is 25.
Concatenation
Joining strings together with + (or & in reference language).
ℹ️
What the exam expects: you should be able to describe, exemplify and implement expressions using addition, subtraction, multiplication, division and exponentiation, and expressions that concatenate strings — plus read and explain code that uses them.

The Arithmetic Operators

Five operators, and you know most of them from maths already — just watch the symbols, because two of them aren't what you'd write on paper:

OperationPythonExampleResult (num1=5, num2=2)
Addition+num1 + num27
Subtraction-num1 - num23
Multiplication*num1 * num210
Division/num1 / num22.5
Exponentiation (to the power of)**num1 ** num225

So multiplication is * (not ×), division is / (not ÷), and "to the power of" is **:

Python — squares and cubes
square = num1 ** 2      # num1 squared
cube = num1 ** 3        # num1 cubed
ℹ️
Two things to note: division always gives a real number (5 / 2 is 2.5 — another reason averages are reals!), and in SQA reference language exponentiation is written with ^, e.g. SET square TO num1 ^ 2.

Using Calculations in Programs

A calculation on its own doesn't achieve much — the result needs to go somewhere. We assign the result of the expression to a variable. The pattern is always: expression on the right, variable on the left.

Python — expressions assigning values
# Two numbers to work with
num1 = 5
num2 = 7

# The expression (right) is worked out, then stored (left)
total = num1 + num2
difference = num1 - num2
product = num1 * num2

And of course, the values usually come from the user. Here's input, process and output working together — the full pattern from analysis, now in real code:

Python — the Exam Scores program, implemented
# Ask the user for their three exam marks
physics = int(input("Enter your Physics mark: "))
computing = int(input("Enter your Computing mark: "))
maths = int(input("Enter your Maths mark: "))

# Add the scores together
total = physics + computing + maths

# Display the total
print("Your total mark is " + str(total))

That's the same program we analysed and designed earlier in the topic — three inputs, one process, one output. Everything connects!

String Concatenation

Concatenation means joining strings together, and it uses the + operator. So + does two completely different jobs: with numbers it adds, with strings it joins.

Python — concatenation
word1 = "Hello"
word2 = "World"
sentence = word1 + word2
print(sentence)                  # HelloWorld

print("My name is " + name)      # joining a message to a variable

Spotted the problem above? "Hello" + "World" gives HelloWorld — concatenation joins exactly what you give it, spaces included (or in this case, not included). Put the space inside one of the strings: "Hello " + "World".

Example — fix the missing space
Python
fName = "Mr"
lName = "Currie"
name = fName + lName
print(name)          # prints "MrCurrie" — where should the space go?
⚠️
You can only concatenate strings with strings. To join a number onto a message, convert it first with str() — e.g. print("Total: " + str(total)). Try it without the str() and Python will complain loudly.

In reference language, concatenation uses the & symbol: SEND "Total is " & total TO DISPLAY.
