Arithmetic Operators

Programs perform calculations using operators, with the result usually assigned to a variable. The National 5 course requires addition, subtraction, multiplication, division and exponentiation (raising to a power):

OperationPythonExampleResult (num1=5, num2=7)
Addition+sum = num1 + num212
Subtraction-sum = num1 - num2-2
Multiplication*sum = num1 * num235
Division/sum = num1 / num20.714…
Exponentiation**sum = num1 ** num278125 (5⁷)

Raising to a power (exponentiation) means multiplying a number by itself — num1 ** num2 is num1num2:

Python — squares and cubes
square = num1 ** 2      # num1 squared
cube = num1 ** 3        # num1 cubed
ℹ️
In SQA reference language, exponentiation is written with ^ — e.g. SET square TO num1 ^ 2.

String Concatenation

Concatenation joins two strings together using +. Strings can be joined in a print() or stored in a new variable:

Python — concatenation
print("Welcome to " + "National 5")
print("My name is " + name)

word1 = "Hello"
word2 = "World"
sentence = word1 + word2      # "HelloWorld"
💡
Watch the spaces! "Hello" + "World" gives HelloWorld. Add the space inside one of the strings: "Hello " + "World".
Full example — calculations and a concatenation to fix
Python
# Basic calculations
num1 = 4
num2 = 10
answer = 0

# Addition
answer = num1 + num2
print("Addition answer: " + str(answer))

# Subtraction
answer = num1 - num2
print("Subtraction answer: " + str(answer))

# Multiply
answer = num1 * num2
print("Multiply answer: " + str(answer))

# String concatenation — try and fix this
fName = "Mr"
lName = "Currie"
name = fName + lName
print(name)                 # prints "MrCurrie" — where should the space go?

Test Yourself

Q1 — Predict the output (3 marks)

What is displayed by each print statement?

a = 3
b = 2
print(a ** b)
print(a * b + 1)
print("3" + "2")
Marking Instructions

9 (3 squared), 7 (6 + 1), 32 — the quotes make these strings, so + concatenates rather than adds. (1 mark each)

Q2 — Write the code (2 marks)

Write a line of Python that calculates the area of a circle (πr², using 3.14) for a radius stored in radius, assigning the result to area.

Marking Instructions

area = 3.14 * radius ** 2 (or 3.14 * radius * radius). 1 mark for correct assignment, 1 mark for correct expression.
