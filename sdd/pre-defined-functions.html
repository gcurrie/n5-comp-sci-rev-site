Introduction

Pre-defined functions are built in to Python. This saves you "reinventing the wheel" each time you need a common job done. Values passed to a function inside the brackets are called parameters.

The National 5 course requires three pre-defined functions (all with parameters):

random
Returns a random integer between two limits — like rolling dice or tossing a coin.
round
Rounds a real number to the nearest whole number, or to a given number of decimal places.
length (len)
Returns the number of characters in a string.

Random

Something random is open to chance — like rolling dice or tossing a coin. random.randint() returns an integer between its two parameters (inclusive). You must import random at the top of the program first:

Python — random numbers
# This program is going to use random numbers
import random

# Generate a random number from 1 to 6
dice = random.randint(1, 6)
Full example — guessing game
Python
# This program is going to use random numbers
import random

# Ask the user to enter a number
guess = int(input("What is your guess?"))
target = random.randint(1, 10)

if guess == target:
    print("Well done, you guessed correctly.")
else:
    print("Sorry, you guessed wrongly")

Length of a String

len() returns the length — the number of characters — in a string. So len("hello") is 5, and len("abc") is 3.

Python — len()
# Display how many characters are in the word "hello"
how_long = len("hello")
print(how_long)
Full example — password length check
Python
# Ask the user to enter a password
passwd = input("Please enter your password")

# The password must be at least 6 characters long
if len(passwd) > 6:
    print("Your password is long enough")
else:
    print("Your password is NOT long enough")

This check could be placed inside a loop so the user is asked again until their password is long enough — see input validation.

Round

round() can round to the nearest whole number, or to a certain number of decimal places (given as a second parameter):

Python — round()
num1 = round(3.14159265)
print(num1)              # 3 — nearest whole number

num2 = round(3.14159265, 2)
print(num2)              # 3.14 — two decimal places

num3 = round(3.14159265, 5)
print(num3)              # 3.14159 — five decimal places
💡
round(total, 2) is perfect for money — it keeps answers to pounds and pence. Expect to use it in average and price calculations.

Test Yourself

Q1 — Predict the output (3 marks)

State the output of each line:

print(len("computing"))
print(round(7.851, 1))
print(round(9.5))
Marking Instructions

9 — nine characters (1 mark). 7.9 — one decimal place (1 mark). 10 — nearest whole number (1 mark).

Q2 — Write the code (2 marks)

Write Python to simulate rolling a 20-sided dice, storing the result in roll. Include any line needed at the top of the program.

Marking Instructions
Suggested answer
import random
roll = random.randint(1, 20)

1 mark for the import, 1 mark for randint with parameters 1 and 20.
