The Five Data Types

Data types are crucial in programming — the computer has to know whether to expect numbers, text, or other types of values. At National 5 you must be able to identify the data types and structures required for a problem, and describe, exemplify and implement them.

Data typeStoresExamples
IntegerWhole numbers45, 2, 122, -7
RealNumbers with a decimal point8.1, 0.99, -2.5
StringText — words, letters, numbers and symbols"PlayerOne", "KA7 2RG"
CharacterA single letter, digit or symbol"E", "%"
BooleanOnly TRUE or FALSETrue, False
Worked Example — spotting data types in a game

Think about the information on a video game's screen:

  • "E" is a character, because it is a single letter.
  • 45, 2 and 122 are integers, because they are whole numbers.
  • The player names are strings, because they are made up of words, letters, numbers and symbols — we use a string whenever we want to store text.
  • A rating of 8.1 is a real number, because it has a decimal point.
  • Whether the game is saved is a Boolean — it can only be true or false.

Worked Example — the class data program

Problem: a program asks the user for the names and ages of everyone in the class. When finished, it displays a message saying how many people are in the class, and their average age.

  • The names are strings, because they are text.
  • The ages are integers — e.g. someone is 15 years old.
  • The number of people in the class is an integer, because you can't have 0.5 of a person.
  • The average is a real number, because it might have a decimal point in it.
⚠️
The last point is really important. If three people are 15, 15 and 16 — those ages are integers — but the average is 15.333…, a real number. Averages come up in exam questions all the time.

Variables

A variable stores a single item of data in a program. Imagine a variable as a box that can hold one item at a time.

Creating a new variable is called declaring. Every variable needs:

  • a meaningful identifier (name) that tells you what it stores — e.g. score for a player's game score
  • a data type — e.g. score is an integer, because scores are whole numbers

How variables work

When a value is assigned to a variable, it's like putting something into the box. Assigning a new value overwrites what was there. Using the variable's name displays its current contents:

SQA Reference Language
SET score TO 15        <# score now holds 15 #>
SET score TO 20        <# 15 is overwritten — score now holds 20 #>
SEND score TO DISPLAY  <# displays 20 #>
SET score TO 0         <# initialised back to 0 #>

Variables can be reset by initialising them — it is good practice to do this at the start of a program:

SQA Reference Language — initialising vs assigning
<# Initialising #>          <# Assigning #>
SET total TO 0              SET total TO 15
SET firstname TO ""         SET firstname TO "Fred"
SET price TO 0.00           SET price TO 2.49
SET found TO FALSE          SET found TO TRUE
Declaring
Creating a new variable and setting its name and data type.
Assigning
Placing a value in a variable.
Initialising
Resetting or clearing the contents of a variable, usually at the start of a program.
One variable per piece of information

A new variable should be declared for each piece of information you need to store. For a program that asks 100m sprinters for their name and times in two heats, then works out their best time, you would need: runnerName, heat1Time, heat2Time and bestTime.

Variables in Python

In Python, a variable is created the moment you assign a value to it. Use meaningful names — age = 15 tells you far more than x = 15:

Python — variables using all five N5 data types
# Variables using all N5 data types
name = "Mr Currie"        # string
firstInitial = "G"        # character
age = 25                  # integer
height = 2.12             # real
teacher = True            # Boolean

# Print statements to print each variable
print(name)
print(firstInitial)
print(age)
print(height)
print(teacher)

Arrays

An array is a data structure. It is similar to a variable, but it can store several items of data — as long as they are all the same type. Think of it as a list of items that must all be on the same subject.

Declaring an array needs three things:

  • a meaningful identifier — e.g. ages for storing pupil ages
  • a data type — all items must share it, e.g. integer
  • a maximum size — each position has an index number to identify it, and indexes start at 0

How arrays work

SQA Reference Language
SET ages(0) TO 15        <# position 0 now contains 15 #>
SET ages(3) TO 12        <# position 3 now contains 12 #>
SET ages(3) TO 14        <# 12 is overwritten — position 3 now holds 14 #>
SEND ages(3) TO DISPLAY  <# displays 14 #>

A new array should be declared when there are a number of similar items of the same type to be stored — like the test scores of a whole class.

Arrays in Python

Say a program asks for 3 test scores, adds them together and prints the total. With variables, that's three separate inputs:

Python — without an array
score1 = int(input("Please enter first score"))
score2 = int(input("Please enter second score"))
score3 = int(input("Please enter third score"))

Now imagine 20 scores — or 100! An array (a list in Python) solves this: it is a whole set of memory locations, one after the other, under one name.

Declaring and initialising

Python — declaring arrays
# An array of five empty strings
pupilnames = [str]*5

# An array of five integers, all set to 0
scores = [int]*5

# An array of ten real numbers
prices = [0.0]*10

# Initialising with known values — nine scores out of 20
scores = [15, 20, 19, 18, 17, 20, 16, 19, 12]

Using elements in the array

Put the index of the element in square brackets — and remember, element numbers start at zero. So in the scores array above, element 0 is 15, element 1 is 20, and element 7 is 19.

Python — accessing and changing elements
scores = [15, 20, 19, 18, 17, 20, 16, 19, 12]

# Get an element by its exact number
firstitem = scores[0]
finalitem = scores[8]

# Use a variable as the index
counter = 4
print(scores[counter])     # would print 17

# Change the values in elements
scores[0] = 17
scores[4] = scores[2]
scores[5] = 5 * 3
scores[6] = scores[2] + 1

Mixing arrays with loops

We can use a loop to traverse the array — that means to travel through it, visiting every element:

Python — traversing an array
# An array of seven names
names = ["Dopey", "Grumpy", "Doc", "Bashful", "Sneezy", "Sleepy", "Happy"]

# The elements are numbered 0 to 6 — loop through and print each name
for counter in range(len(names)):
    print(names[counter])

# Fill an array from user input
scores = []
for counter in range(5):
    score = int(input("Please enter score "))
    scores.append(score)
print(scores)
💡
Traversing an array is a very useful skill for National 5 — this sort of problem will probably come up in both the exam and the assignment. See Standard Algorithms for more.

Test Yourself

Q1 — Identify the data types (4 marks)

A cinema booking program stores: the film title, the number of seats booked, the price per seat, and whether the customer is a member. State the most suitable data type for each.

Marking Instructions

Film title — string. Number of seats — integer. Price per seat — real. Member — Boolean. (1 mark each)

Q2 — Arrays (2 marks)

A program needs to store the test scores of 20 pupils. Explain why an array is a better choice than 20 separate variables.

Marking Instructions

One array stores all 20 values under a single name (1 mark), so a loop can be used to process every score with a few lines of code instead of repeating code 20 times — more efficient (1 mark).

Q3 — Reading array code (2 marks)

What is displayed by this code?

scores = [15, 20, 19, 18, 17]
scores[1] = scores[4]
print(scores[1])
Marking Instructions

17 — scores[4] is 17, which overwrites the 20 at index 1 (2 marks; 1 mark if 20 given with correct reasoning about indexes starting at 0).
