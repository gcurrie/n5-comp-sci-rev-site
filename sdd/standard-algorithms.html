Introduction

There are three standard algorithms in the National 5 course. You must be able to describe, exemplify and implement each one — and they come up in both the exam and the assignment:

Input validation
Checking that input is acceptable, and asking again until it is.
Running total within a loop
Adding up a list of values, one per pass of a loop.
Traversing a 1-D array
Accessing each element of an array from first to last.

Input Validation

Input validation checks that you have entered the right type of data in each place. Note: it's not checking that the data is actually correct — just that it is the right sort of data. Common examples: a password must have a minimum length; an age must be a sensible whole number; a percentage must be between 0 and 100.

The algorithm uses a conditional loop:

  1. Ask the user for input
  2. While the input is not valid…
  3.   Display an error message
  4.   Ask for the input again
  5. End loop
SQA Reference Language — input validation (while loop)
RECEIVE number FROM KEYBOARD
WHILE number < 10 OR number > 20 DO
    SEND "Error, please enter again" TO DISPLAY
    RECEIVE number FROM KEYBOARD
END WHILE
Python — validating an age
age = int(input("Enter your age: "))
while age < 11 or age > 18:
    print("Error, age must be between 11 & 18")
    age = int(input("Enter your age: "))
print("Your age is acceptable")
Python — validating a password length
password = input("Please enter a new password: ")
while len(password) < 7:
    print("Your password must be at least 7 characters long")
    password = input("Please re-enter your new password: ")
print("Your password is long enough")
ℹ️
Notice the input line appears twice — once before the loop and once inside it. That's deliberate: the program needs a first value to test, and must ask again inside the loop or it would never end.

Running Total Within a Loop

The running total algorithm keeps a cumulative sum of numbers — from user input or from an array. The total is initialised to 0, then each value is added on inside a loop.

  1. Set total to 0
  2. Start a loop
  3.   Get the next value (from input or the array)
  4.   Add it to the total
  5. End loop, then display the total
Python — running total from user input
# Example 1 — running total without an array
total = 0
for counter in range(5):
    price = int(input("Please enter a price: "))
    total = total + price
print("The total price is £" + str(total))
Python — running total from an array
# Example 2 — running total with an array
prices = [5, 25, 32, 10, 3]
total = 0
for counter in range(len(prices)):
    total = total + prices[counter]
print("The total price is £" + str(total))
SQA Reference Language — running total (fixed loop)
SET total TO 0
FOR counter FROM 0 TO 4 DO
    SET total TO total + prices(counter)
END FOR
SEND "The total is " & total TO DISPLAY
💡
Calculating an average? Add the values inside the loop, but do the division once, after the loop ends — dividing on every pass is wasted work and loses efficiency marks. A running total can also be used with a conditional loop — e.g. 2019 exam Q19b asked users to keep entering numbers until the total reached 100 or more.

Traversing a 1-D Array

Arrays cut out repetitive variables (score1, score2, …) and loops cut out repetitive code — traversing an array combines both. It means using a loop to travel through the array, visiting each element from first to last:

  1. Start a fixed loop for the number of array elements
  2.   Use the element at position [counter]
  3. End the loop
Python — traversing an array
# An array of seven names
names = ["Dopey", "Grumpy", "Doc", "Bashful", "Sneezy", "Sleepy", "Happy"]

# The elements are numbered 0 to 6 — loop through and print each
for counter in range(7):
    print(names[counter])
Python — filling then displaying an array
names = []
for counter in range(4):
    names.append(input("Please enter your name: "))

for counter in range(len(names)):
    print(names[counter])
SQA Reference Language — traversing a 1-D array
FOR counter FROM 0 TO 6 DO
    SEND names(counter) TO DISPLAY
END FOR

Test Yourself

Q1 — Name the algorithm (3 marks)

Name the standard algorithm used in each situation:

  1. Adding up the cost of every item in a shopping basket.
  2. Making sure a mark entered is between 0 and 100.
  3. Displaying every name stored in an array.
Marking Instructions

a) Running total within a loop. b) Input validation. c) Traversing a 1-D array. (1 mark each)

Q2 — Write input validation (4 marks)

Using a design technique or code of your choice, write an input validation algorithm to get a number of tickets between 1 and 6 inclusive from the user.

Marking Instructions
Python — suggested answer
tickets = int(input("How many tickets (1-6)? "))
while tickets < 1 or tickets > 6:
    print("Error — you can book between 1 and 6 tickets")
    tickets = int(input("How many tickets (1-6)? "))

1 mark: initial input. 1 mark: conditional loop with correct complex condition. 1 mark: error message inside loop. 1 mark: input repeated inside loop.

Q3 — Trace the running total (2 marks)

What is displayed when this code runs?

values = [4, 9, 1]
total = 0
for counter in range(len(values)):
    total = total + values[counter]
print(total)
Marking Instructions

14 — the loop adds 4, then 9, then 1 (0+4=4, 4+9=13, 13+1=14). (2 marks for correct answer with working; 1 mark for correct method with arithmetic slip)
