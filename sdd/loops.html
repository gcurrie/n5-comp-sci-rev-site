Fixed Loops

Think of Bart Simpson writing the same line on the blackboard over and over. Without loops, printing "Hello world" nine times means nine print statements:

Python — very inefficient!
print("Hello world")
print("Hello world")
print("Hello world")
# ...and six more times...

This is very inefficient. Suppose we wanted to change the message — we'd have to go back and change every line individually, taking up time (and boring us). Instead, code inside a fixed loop repeats a certain (fixed) number of times:

Python — fixed loop
for counter in range(9):
    print("Hello world")

counter is the loop variable — it could be called anything (even bananas), but it is good practice to give it a meaningful name.

Fixed loop with a running total
Python
# Ask the user to enter 10 numbers and keep a running total
total = 0
for counter in range(10):
    number = int(input("Please enter a number"))
    total = total + number

# Show total once the loop is done
print(total)
SQA Reference Language — fixed loop
REPEAT 10 TIMES
    RECEIVE number FROM (INTEGER) KEYBOARD
    SET total TO total + number
END REPEAT

Conditional Loops

A conditional loop (in Python, a while loop) repeats only while a condition is true. Think of it as a combination of a fixed loop and an if statement — you can use all the same conditions in a while loop that you would in an if.

In this example, if the number entered is more than 100, part of the program repeats, asking the user to enter the number again. Once the condition fails, the loop stops and the program continues:

Python — while loop
# Initialise the variable
mynumber = 0

# Ask the user to enter a number
mynumber = int(input("Please enter a number"))

# Example of a while loop
while mynumber > 100:
    print("That number is too big!")
    mynumber = int(input("Please enter a number"))
SQA Reference Language — conditional loop
WHILE mynumber > 100 DO
    SEND "That number is too big!" TO DISPLAY
    RECEIVE mynumber FROM (INTEGER) KEYBOARD
END WHILE

Beware the Infinite Loop

Be careful you don't get stuck in an infinite loop — make sure your condition can always end. This loop never finishes, because 100 is always more than 5:

Python — oh no, an infinite loop!
while 100 > 5:
    print("One hundred is still more than five")
💡
There's a famous Big Bang Theory clip (S2E13) where Sheldon builds a flowchart for making a friend and gets stuck going round and round it — until Howard fixes it by making sure the loop's condition can end. That's exactly how loops appear on flowcharts: a decision whose arrow points back up.

Test Yourself

Q1 — Fixed or conditional? (2 marks)

For each program, state whether a fixed or conditional loop is more suitable, and why:

  1. Asking for the marks of the 30 pupils in a class.
  2. Asking for a password until the correct one is entered.
Marking Instructions

a) Fixed loop — the number of repetitions (30) is known in advance (1 mark). b) Conditional loop — you can't know how many attempts the user will need; it repeats while the password is wrong (1 mark).

Q2 — How many times? (2 marks)

How many times does each loop print a message?

for counter in range(6):
    print("A")

count = 0
while count < 4:
    print("B")
    count = count + 1
Marking Instructions

"A" is printed 6 times (range(6) gives 0–5) (1 mark). "B" is printed 4 times (count goes 0,1,2,3) (1 mark).

Q3 — Spot the infinite loop (2 marks)

Explain why this loop never ends, and rewrite one line to fix it.

count = 1
while count <= 5:
    print(count)
Marking Instructions

count never changes inside the loop, so count <= 5 is always true (1 mark). Fix: add count = count + 1 inside the loop body (1 mark).
