What is Selection?

Selection constructs let a program ask a question and follow different paths depending on the answer. Think of a daily decision: IF today is a weekday THEN go to school.

Pseudocode — simple IF
1. IF today = "weekday" THEN
2.     Go to school
3. END IF

Line 1 is the condition; line 2 only runs if the condition is true. Commands between IF and END IF run exclusively when the condition is met — otherwise the program continues past END IF.

An ELSE adds an alternative path — go to school, or else go to the shops:

Pseudocode — IF … ELSE
1. IF today = "weekday" THEN
2.     Go to school
3. ELSE
4.     Go shopping
5. END IF

Line 2 runs if the condition is true; line 4 runs if it is false. Only one branch ever runs — the branches are mutually exclusive.

Comparison Operators

Conditions compare two values using these operators:

MeaningMaths / exam papersPython
Equal to===
Not equal to≠!=
Less than<<
Greater than>>
Less than or equal to≤<=
Greater than or equal to≥>=
⚠️
In Python, double equals == tests equality — a single = assigns a value. Mixing them up is a classic syntax error.

Logical Operators & Complex Conditions

Logical operators build more complex expressions by joining two conditions together. There are three: AND, OR and NOT. (If you have done any electronics, these are the same basic logic operations used in signal processing.)

OperatorResult is TRUE when…
ANDboth conditions are true
ORat least one condition is true
NOTthe condition is false (it flips the answer)

A complex condition is any conditional statement that uses two or more conditions:

Pseudocode — complex conditions
IF num1 > 3 OR num2 > 13 THEN
IF num1 > 2 AND num2 < 13 THEN
IF answer = "Yes" OR answer = "No" THEN
IF NOT (num1 = 5 AND num2 < 10) THEN
Worked Example — evaluating a complex condition

Evaluate height >= 2500 AND height < 3000 when height is 2750:

  • First condition: 2750 ≥ 2500 → true
  • Second condition: 2750 < 3000 → true
  • true AND true → the whole expression is true

IF Statements in Python

Remember the diamond decision symbol in flowcharts? This is how those yes/no decisions are implemented. Note the colon at the end of the if line, and the indentation of the code inside the branch:

Python — if
# Ask the user to enter a password
passwd = input("Please enter the password")

# Is access granted?
if passwd == "hello123":
    print("Access granted")
Python — if … else
# Ask the user for their age
age = int(input("Please enter your age"))

# Old enough to drive?
if age >= 17:
    print("Broom broom")
else:
    print("Sorry, no drive yet")
Full example — quiz and age check
Python
# Simple conditions
answer = input("What is the capital of Scotland? ")
if answer == "Edinburgh":
    print("Well done, you are correct!")
else:
    print("Wrong")

age = int(input("Please enter your age"))
if age > 16:
    print("You're old enough to learn to drive")
else:
    print("You need to wait a little longer")

Multiple Selection — elif

Sometimes there are more than two possible outcomes. Think about exam grades: if the mark is 70 or more, the student gets an A. Otherwise, if it is 60 or more, they get a B. Otherwise, if it is 50 or more, a C — and otherwise, no award.

elif is short for else-if. Each elif is followed by a new condition, checked only if the conditions above it were false. This is efficient: if the student got an A, the program never has to check for a B or C.

Python — if / elif / else
# Ask for percentage mark
mark = int(input("Please enter percentage mark"))

# Check which category the mark goes in
if mark >= 70:
    grade = "A"
elif mark >= 60:
    grade = "B"
elif mark >= 50:
    grade = "C"
else:
    grade = "F"

# Print the grade
print(grade)
Full example — with complex conditions
Python
# Multiple selection (else if)
score = int(input("Please enter your test score: "))

if score > 100:
    print("Your score cannot be larger than 100%")
elif score >= 70 and score < 100:
    print("You have achieved an A")
elif score >= 60 and score < 70:
    print("You have achieved a B")
elif score >= 50 and score < 60:
    print("You have passed")
else:
    print("You have not passed")

Test Yourself

Q1 — Evaluate the conditions (3 marks)

If x = 10 and y = 5, state whether each expression is true or false:

  1. x > 8 AND y > 8
  2. x > 8 OR y > 8
  3. NOT (x == 10)
Marking Instructions

a) False — y is not greater than 8. b) True — one condition (x > 8) is enough for OR. c) False — x == 10 is true, and NOT flips it. (1 mark each)

Q2 — Write the code (3 marks)

A theme park ride requires riders to be at least 120 cm tall and no taller than 200 cm. Write a Python if statement that displays "You may ride" when the height stored in height is allowed, and "Sorry" otherwise.

Marking Instructions
Suggested answer
if height >= 120 and height <= 200:
    print("You may ride")
else:
    print("Sorry")

1 mark for the complex condition with AND, 1 mark for correct operators (≥ 120, ≤ 200), 1 mark for the if/else structure with both outputs.

Q3 — Reading code (2 marks)

Using the grades example, state what grade is printed when the user enters 60, and explain why the program never checks mark >= 50 for that input.

Marking Instructions

Grade B is printed (1 mark). Once mark >= 60 is true, the elif chain stops — later conditions are only checked if all earlier ones were false (1 mark).
