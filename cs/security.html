Introduction

Security is a bigger part of the Higher course (and the NPA Cyber Security). For National 5, you only need to be able to briefly describe the role of a firewall, and how encryption is used in modern communications.

Firewalls

A firewall is software or hardware that restricts access to your network. The firewall decides what data is allowed through the connection, and can block risky connections, or connections from specific computers (e.g. a hacker).

⚠️
Firewalls protect against hackers, not viruses — don't mix them up in an exam answer.

Encryption

Encryption protects data by making it coded, or unreadable, so that only the intended recipient can understand it.

We usually encrypt sensitive data when sending it over the Internet. Even if a criminal got access to the data, it wouldn't make sense to them — it would be scrambled and unreadable. WhatsApp, for example, routinely encrypts all messages sent across its network.

💡
In previous National 5 assessments, firewall and encryption questions have been very short — usually one-mark questions asking for a brief description of what each does. Sometimes the answer is literally the single word "encryption"!

Test Yourself

Q1 — Firewall (1 mark)

Describe the role of a firewall.

Marking Instructions

It restricts access to a network by deciding which data/connections are allowed through, blocking risky or unauthorised connections (e.g. hackers).

Q2 — Encryption (2 marks)

A shop's website sends customers' payment details over the Internet. Explain how encryption protects these details.

Marking Instructions

The details are scrambled/encoded so they are unreadable (1 mark); only the intended recipient can decode and read them, so intercepted data is useless to a criminal (1 mark).
