Components of the Computer

Computers have a processor, which has three parts: registers, the ALU and the control unit. The processor does the computer's "thinking". Data and instructions from the programs you are running are stored in memory locations, each with a unique address, and are moved between memory and the processor along buses.

You need to know how these are linked together — this is a simplified version of how it works:

  • The address bus carries the address of the memory location being accessed, from the processor to memory.
  • The data bus carries the actual data between the processor and memory.

Inside the Processor

Registers
A small amount of memory inside the processor that stores data temporarily, especially during calculations.
Control unit
Decodes and executes instructions, and keeps the other parts of the processor in time with its clock.
ALU (Arithmetic Logic Unit)
Does all the calculations and logical decisions a program requires — when your if statements use ==, < or >, that's the ALU at work.

Interpreters & Compilers

We write our programs in Python. Python is easy for us to read (it looks a bit like English), but it isn't readable by the computer — the computer only understands machine code (binary 1s and 0s). Before a program can run, it must be translated into machine code by an interpreter or a compiler. Both are types of translator.

InterpreterCompiler
How it translatesLine-by-line, every time the program runsThe whole program at once, producing a machine-code file
ErrorsShown "live" as they happen — great while developingAll syntax errors reported together after compiling
SpeedSlower to run — translated every timeRuns fast once compiled, but you wait for compilation

What we use — Python — is interpreted: you see your errors live as they happen. A compiler would find all the syntax errors once at the start, but you'd have to wait for the whole program to compile before running it.

These are usually short 1–2 mark questions. Learn a few advantages of each, and remember: all programs must be translated to machine code before they can run.

Test Yourself

Q1 — Processor parts (3 marks)

Name the three parts of the processor and state the purpose of each.

Marking Instructions

Registers — temporary storage inside the processor. Control unit — decodes/executes instructions and keeps everything in time. ALU — performs calculations and logical decisions. (1 mark each)

Q2 — Buses (2 marks)

Describe the purpose of the address bus and the data bus.

Marking Instructions

The address bus carries the unique address of the memory location to be accessed (1 mark); the data bus transfers the data between the processor and that memory location (1 mark).

Q3 — Translators (2 marks)

Explain why a program written in Python must be translated before it can run, and state which type of translator finds errors line-by-line.

Marking Instructions

The processor only understands machine code (binary), so high-level code must be translated first (1 mark). An interpreter translates and reports errors line-by-line (1 mark).
