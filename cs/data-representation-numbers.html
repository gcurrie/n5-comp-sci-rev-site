What Are Binary Numbers?

Computers store whole numbers using binary — a number system that uses only the digits 1 and 0. At National 5 you must be able to convert between denary (the base-10 numbers we use) and binary, in both directions.

  • Binary — what the computer uses, e.g. 10011101
  • Denary — what we use, e.g. 157

We work with eight place values (columns), starting at 1 on the right and doubling each time:

1286432168421
10011101

To convert 10011101 to denary, add up all the columns with a 1 in them: 128 + 16 + 8 + 4 + 1 = 157.

Converting Binary → Denary

Worked Example — 01011100 to denary
1286432168421
01011100

Add up all the columns with a 1 in them: 64 + 16 + 8 + 4 = 92.

Converting Denary → Binary

You also need to be able to write a denary number in binary. There are a few methods — this one is the simplest:

Worked Example — 87 to binary

Draw the place value columns and ask: which of these columns, when added up, would make 87?

  1. 128 doesn't go into 87, so there must be a 0 in that column.
  2. 64 does go into 87, so write a 1 in the 64 column. This leaves 87 − 64 = 23.
  3. Which remaining columns add up to 23? 16 + 4 + 2 + 1 — put a 1 in each of those columns.
  4. Finally, fill in the empty columns with 0s.
1286432168421
01010111

So 87 in binary is 01010111. Check your working by adding the columns with a 1: 64 + 16 + 4 + 2 + 1 = 87 ✓

ℹ️
At National 5 you only deal with positive integers in binary. (Negative numbers using two's complement are a Higher topic.)

Floating Point — Mantissa & Exponent

Real (decimal) numbers like 0.5571257 are stored using floating point representation. If you are asked how floating point numbers are stored, the answer is: with a mantissa and an exponent.

The idea comes from scientific notation:

Example
5.8125 = 0.58125 × 10⁴

mantissa = 58125     (remove the decimal point)
exponent = 4         (remove the ×10)
Mantissa
Governs the precision of the number. Pi can be shortened to 3.14, but 3.14159265359 is more precise — the longer the mantissa, the more precise the number.
Exponent
Governs the range of the number. The higher the exponent, the larger the number can be.
💡
Exam gold: this question has come up in the same way in every N5 exam — you're given a floating point number and asked to pick out the two parts. Practise identifying the mantissa and exponent!

Test Yourself

Q1 — Binary to denary (2 marks)

Convert the binary number 01101001 to denary.

Marking Instructions

64 + 32 + 8 + 1 = 105. (2 marks; 1 mark for correct method with one slip)

Q2 — Denary to binary (2 marks)

Convert the denary number 203 to 8-bit binary.

Marking Instructions

203 = 128 + 64 + 8 + 2 + 1 → 11001011. (2 marks)

Q3 — Floating point (2 marks)

A number is represented as 0.110101 × 2¹⁰¹. Identify the mantissa and the exponent.

Marking Instructions

Mantissa: 110101 (1 mark). Exponent: 101 (1 mark).
